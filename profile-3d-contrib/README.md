# 3D Contribution Graphs

此目录由 GitHub Actions 自动生成，每日 UTC 18:00 自动更新。
每次运行会生成以下 9 种风格的 SVG：

- `profile-green-animate.svg` - 绿色动画版
- `profile-green.svg` - 绿色静态版
- `profile-season-animate.svg` - 季节色动画版
- `profile-season.svg` - 季节色静态版
- `profile-south-season-animate.svg` - 南半球季节色动画版
- `profile-south-season.svg` - 南半球季节色静态版
- `profile-night-view.svg` - 夜景版
- `profile-night-green.svg` - 暗夜绿版（README 暗色模式使用）
- `profile-night-rainbow.svg` - 暗夜彩虹版
- `profile-gitblock.svg` - 等距方块风格版

> ⚠️ 请勿手动编辑此目录中的 SVG 文件，它们会被 GitHub Actions 自动覆盖。
